# Календарь звонков

Сервис записи на звонки с одним Владельцем календаря.

## Термины

**Владелец**:
Человек, на звонок с которым может записаться Гость. Владелец задаёт типы встреч.

**Гость**:
Человек, который записывается на звонок с Владельцем.

**Тип встречи**:
Вариант звонка с Владельцем с заданными названием, описанием и длительностью.

**Запись**:
Подтверждённое бронирование Гостем времени для звонка с Владельцем по выбранному типу встречи.
